A. Logic & Patterns

Answer each question in your own words. Check a model response when ready, and mark the question complete.

Q1

Sequence

The sequence is 4, 10, 16, 22, … What are the next two numbers?

28, 34. Add 6 each time.
Q2

Odd one out

Which item does not belong: triangle, square, circle, cube? Explain.

Cube: it is three-dimensional; the others are 2D shapes.
Q3

Alternating shapes

A pattern repeats: star, circle, circle, star, circle, circle, … What are the next three shapes?

Star, circle, circle.
Q4

Rule machine

A machine subtracts 2 from an input, then multiplies the result by 3. What is the output for input 7?

(7 − 2) × 3 = 15.
Q5

Movement

A robot moves 8 steps north, then 3 steps south. How far and in which direction is it from the start?

5 steps north.
Q6

Coordinates

A robot starts at (1, 2). It moves right 4 and down 1. What are its final coordinates?

(5, 1), assuming down decreases the y-coordinate.
Q7

Logic rule

A rule says: “Every green card is a triangle.” You find a green square. What does this tell you about the rule?

The rule is not true for every green card; the green square is a counterexample.
Q8

Compare speeds

Robot A travels 18 cm in 6 seconds. Robot B travels 20 cm in 4 seconds. Which is faster, and by how much?

A = 3 cm/s; B = 5 cm/s. Robot B is faster by 2 cm/s.
Q9

Turn pattern

A robot repeats the turn sequence right, left, left. After right, left, left, right, left, what is the next turn?

Left, continuing the repeating three-turn sequence.
Q10

Ordering

Box X is heavier than Y. Box Z is lighter than Y. Order the boxes from lightest to heaviest.

Z, Y, X.

B. Algorithm Design

Answer each question in your own words. Check a model response when ready, and mark the question complete.

Q11

Put steps in order

A delivery robot must pick up a parcel, travel to the room, check the room number, deliver the parcel, and return to base. Put these actions in a sensible order.

Pick up parcel → travel to room → check room number → deliver parcel → return to base.
Q12

Conditional

Write pseudocode for a plant-monitoring system that waters a plant only when the soil is dry.

IF soil_is_dry THEN water_plant ENDIF.
Q13

Loop

Write a loop that makes a robot inspect each of 5 storage shelves once.

REPEAT 5 TIMES: inspect_shelf; move_to_next_shelf (except after the last shelf).
Q14

Missing step

An algorithm is: 1. Write a message. 2. Press Send. What important step should be added before sending?

Review/check the message and recipient before pressing Send.
Q15

Access logic

A door opens only when a valid card is scanned AND the emergency lock is off. Write the condition for opening.

IF valid_card AND NOT emergency_lock THEN unlock_door.
Q16

Route planning

A robot must visit the Lab and Library, then return to Base. It starts at Base. Describe a route that visits both places and returns.

Base → Lab → Library → Base, or Base → Library → Lab → Base, assuming paths connect them.
Q17

Safe repetition

A robot retries a locked door until it opens. Why is an unlimited loop unsafe? Suggest a safer algorithm.

It may waste power or keep pushing unsafely. Limit attempts, then stop and alert a human.
Q18

Sequence

A robot must move forward 2 m and then turn right. Why does the order of these commands matter?

Changing the order changes the path and final position.
Q19

Efficiency

Compare checking for obstacles after every movement step with checking only once at the beginning. Which is safer and why?

Checking each step is safer because obstacles may appear or be missed along the route.
Q20

Pseudocode

Write pseudocode for a line-following robot that follows a line and stops when a red marker is detected.

WHILE red_marker_not_detected: follow_line; IF red_marker_detected: stop_motors.

C. Robotics Systems & Safety

Answer each question in your own words. Check a model response when ready, and mark the question complete.

Q21

Sensor choice

A robot must turn on a lamp when a room becomes dark. Which sensor could it use, and what does it measure?

A light sensor; it measures light intensity.
Q22

Actuator choice

A robot gripper needs to open and close to pick up objects. Name an appropriate actuator.

A servo motor or another suitable motor-driven mechanism.
Q23

Input-process-output

For a robot that moves when a button is pressed, identify the input, processing, and output.

Input: button state; processing: controller checks whether it is pressed; output: motor command/movement.
Q24

Power and motion

A robot's motors become slower when the battery is nearly empty. Give a likely reason and one test.

Low voltage/current may limit motor performance. Measure battery voltage under load and compare with a charged battery.
Q25

Human safety

A mobile robot approaches a person unexpectedly. Describe a safe response and a mechanism that could trigger it.

Stop or slow down; use a distance sensor or emergency stop and a fail-safe stop routine.
Q26

Wall detection

Which sensor could help a robot detect a wall before colliding with it? What limitation should be considered?

An ultrasonic or time-of-flight distance sensor; readings can be affected by material, angle, range, or environment.
Q27

Lift a barrier

A robot must raise and lower a small barrier repeatedly. Suggest an actuator and a design consideration.

A servo or geared motor; consider torque, travel limits, secure mounting, and pinch points.
Q28

System flow

Arrange the stages of a basic robot control loop: decision, sensor reading, motor output, processing.

Sensor reading → processing → decision → motor output, then repeat.
Q29

Fail-safe

A drive motor controller stops responding while a robot is moving near people. What should the system aim to do?

Enter a safe state: stop motion where possible, signal a fault, and require a safe recovery/check.
Q30

Detection rate

A sensor correctly detects 17 out of 20 test objects. What is its detection rate as a percentage?

17 ÷ 20 × 100 = 85%.

D. Debugging & Experiments

Answer each question in your own words. Check a model response when ready, and mark the question complete.

Q31

Unexpected curve

A two-wheel robot curves left even though both motors are commanded to run forward at the same speed. Give two possible causes and a test.

Possible causes: unequal motor speed, wheel friction/diameter, misalignment. Test each motor separately and compare wheel rotation or distance on a straight run.
Q32

Button input

A program starts automatically and ignores the Start button. Name a likely programming issue and how to investigate it.

The button input may not be read correctly or the code may not wait/check its state. Log the input value and inspect the start condition.
Q33

Repeatable fault

A robot fails at the same corner in four trials. What data should be recorded to help diagnose the fault?

Starting position, route, sensor readings, motor commands, timing, battery state, and the exact failure point.
Q34

Fair test

You want to compare two wheel designs. Name at least three variables that should be kept constant.

Robot mass, motor/power setting, surface, starting position, route, and measurement method.
Q35

Measurement error

The target travel distance is 120 cm, but the robot travels 111 cm. Calculate the absolute error and percentage error relative to the target.

Absolute error = 9 cm. Percentage error = 9/120 × 100 = 7.5%.
Q36

Light experiment

Plan a fair test to find out how sensor distance from a lamp affects the light reading.

Change only distance; keep lamp, sensor orientation, room lighting, and measurement time constant. Record repeated readings at set distances.
Q37

Outlier

Sensor readings are 12, 13, 12, 11, 29, 12. Which reading appears unusual? What should you do before excluding it?

29 appears to be an outlier. Repeat the measurement and check for a recording or sensor error before deciding whether to exclude it.
Q38

Two variables

A student changes both motor speed and wheel size, then the robot improves. Why can they not tell which change caused the improvement?

Two variables changed at once, so the cause cannot be isolated. Test one variable at a time.
Q39

Hypothesis test

Hypothesis: a blue marker will be detected more reliably than a red marker. Describe a fair test.

Use the same sensor, distance, lighting, speed, and number of trials; change only marker colour and compare detection rates.
Q40

Evaluate improvement

Before a code change, a robot failed 7 times in 20 trials; afterward, it failed 3 times in 20 trials. Calculate both failure rates and give one limitation of the test.

Before: 35%; after: 15%. Small sample size and possible uncontrolled differences limit confidence.
